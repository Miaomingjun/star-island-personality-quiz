# 星屿纪行人格测试

一个独立制作的微信小程序练习项目：完成 12 道趣味题后，展示人格倾向、原创角色匹配和可保存的分享海报。结果仅供娱乐与自我探索参考，不构成心理诊断或专业测评。本项目与 The Myers-Briggs Company、微信官方及任何动漫作品方无关联。

## 公开演示版说明

这是从私人开发目录单独整理出的**本地图片演示版**，不是已上架的微信小程序，也不是原开发目录的完整备份。公开版保留了页面、题目、匹配和海报逻辑；去掉了真实微信 AppID、云环境映射、后台记录、迁移备份与个人开发设置。角色图片使用中性的文件名与 ID。

32 张角色图及 4 张页面主图由项目作者使用自己的 ChatGPT 账号生成，未使用他人图片作参考；其余装饰与占位图另有本地制作记录。项目中的人物名称、设定与文案为本项目内容。AI 生成并不自动消除第三方权利风险，若发现素材或内容与他人作品存在冲突，请通过 GitHub 仓库 Issue 告知。

## 本地查看

1. 克隆仓库，使用微信开发者工具导入本目录。
2. `project.config.json` 中的 `touristappid` 仅是公开示例值；如果开发者工具要求 AppID，请使用你自己的测试号或小程序 AppID，并把个人配置保存在不提交的 `project.private.config.json` 中。
3. 本版图片直接从 `assets/` 读取，不连接原作者的微信云环境。素材约 109 MB，主要用于学习和作品展示；它不是可直接上传审核的精简包。

## 目录

- `pages/`：首页、答题、结果、海报页面。
- `data/`：12 道题及原创角色数据。
- `utils/`：人格倾向计算、角色匹配、本地图片适配。
- `assets/`：页面背景、角色插图和占位图。

本仓库暂未附加开源许可证；公开可见不等于授权他人复制或再分发。若将来决定开放复用，可以再选择合适的许可证。
